# 结业 B 知识整合

第三课提供工具协议与有界循环，第四课提供控制图和框架取舍，第五课提供规则与能力连接，第六课提供证据与记忆，第七课提供评测与恢复，第7.5课提供复杂度决策，第八课提供执行界面边界。

选择 RAG 不必为了满足“Agent”名称增加两个角色；选择多 Agent 则必须说明为什么分工有收益、如何传状态、如何合并和停止。原课两条结业方案是二选一，不要求为了结业同时完成两套复杂架构。

评测材料应来自问题定义和真实失败，参考答案需可核查。固定 mock 能测试协议；真实模型试跑能观察行为；业务可用还需要实际场景验收。三种证据不能互相冒充。

示范与完整原 rubric 都已本地提供。结业要求真实问题与独立判断，示范代码帮助你从可运行基线出发，不替代个人作品。
