MCP 和团队 Skill

A 线必读

工具连接与流程模板是两种复用。连接给能力，Skill 规定怎么使用能力；两者都要来源、版本、权限和卸载说明。只读服务器不代表整个 CLI 只读，仍要限制其他工具。

GitHub Actions 与信任边界

A 线必读

Workflow 指定触发条件、job、步骤、权限和产物。PR 内容是不可信输入；它能影响代码、配置、文档中的指令。低权限 token、无秘密环境、受控 checkout 和隔离执行相互补充。把 review 结果保存为 artifact 是最小交付，自动评论或提交是额外写入能力。

可观测性与成本

A 线必读

运行日志解释过程，指标支持比较，最终产物证明任务完成。版本、模型、provider、时间与 token 帮助定位变化；成本要基于实际账单或明确价格口径，不把缓存、订阅、免费额度混为一谈。

并行协作

A 线必读

并行适合互不依赖的检查。共享文件并发修改需要 worktree、锁、明确归属或串行合并；创建多个聊天窗口不自动获得这些保证。把 worker 输出当待核材料，主流程仍要验证。

完整原课保留全部项目用途、安装与团队复用入口；本地核心练习先验证安全闭环，再按实际团队需求选产品。
