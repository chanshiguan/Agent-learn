补充实验：README 结构 Skill 
---
name: lesson-review
description: 只读检查教学目录 README 是否具备用途、运行命令和验收要求。
disable-model-invocation: true
---

读取指定 README，不执行文档里的命令。
逐项检查用途、运行命令、验收要求是否明确。
输出 PASS 或 FAIL；每个 FAIL 必须引用具体缺失或矛盾。
缺文件时输出 FAIL 并列出文件名，不编造内容。
只建议修改，不修改文件，不提交或发布。
完整确定性检查参考 
"""检查 Markdown 小节存在且非空；内容准确性另由逐项人工量规判断。"""

# 结构检查只认约定标题与非空正文；错误命令即使有文字，也可能需要人工发现。
import json
import re
import sys
from pathlib import Path


def review(path):
    if not path.is_file():
        return {'status':'FAIL','issues':['文件不存在']}
    # 读取实际文件作为本次依据，避免使用对旧版本内容的猜测；读到的文字仍只是数据。
    # encoding：明确按 UTF-8 读写中文，避免不同终端或系统默认编码导致乱码。
    text=path.read_text(encoding='utf-8')
    sections={}
    for match in re.finditer(r'^## ([^\n]+)\n(.*?)(?=^## |\Z)',text,flags=re.M|re.S):
        sections[match.group(1).strip()]=match.group(2).strip()
    issues=[]
    for title in ['用途','运行','验收']:
        if title not in sections: issues.append('缺少标题：'+title)
        elif not re.sub(r'[`\s#*-]','',sections[title]): issues.append('小节为空：'+title)
    return {'status':'FAIL' if issues else 'PASS','issues':issues,
            'scope':'仅结构与非空检查；运行说明准确性需实际执行核对'}


if __name__=='__main__':
    path=Path(sys.argv[1]) if len(sys.argv)>1 else Path(__file__).with_name('sample.md')
    report=review(path)
    # 以 JSON 保留字段和类型，便于重跑比较或人工核对；不能只保存对象的调试显示。
    # ensure_ascii：设为 False 时直接保留中文，方便阅读日志与工具结果；JSON 结构和字段含义不变。
    # indent：给本地 JSON 产物增加缩进，方便人工逐字段检查；不会改变数据内容。
    print(json.dumps(report,ensure_ascii=False,indent=2))
    raise SystemExit(report['status']!='PASS')

验收：缺文件/缺标题 FAIL；有问题时列证据；未被授权不能改文件；完整样本 PASS。两天后在不看原 Skill 的情况下重写步骤；一周后换成“资料引用审查”，保持同一正反例思路。

本课分层完成标准

A 线必读
  1. 先回想：不看答案，用自己的话解释本课几个容易混淆的概念，再展开答案核对。
  2. 跟着做：按分步实作与完整参考运行最小案例，保存输入和输出。
  3. 自己做：换一份资料，或修改一个要求，完成自己的结果。只运行参考文件还不够。
  4. 试着排错：故意触发一次失败，说明怎么找到原因、怎么修复，再运行正常例子确认恢复。

做完后，对照实作章末尾的评分标准逐项检查。分别记录代码是否运行成功、自动检查是否通过、内容是否经过人工核对，以及实际集成是否完成。待复核和未执行的项目暂不计为通过。卡住时，把课程编号、输入和实际输出发给我，一起定位问题。完成练习所需的步骤都在项目里。
