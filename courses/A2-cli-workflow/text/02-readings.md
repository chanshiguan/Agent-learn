# A2 参考知识整合

## 官方规则与 Skills 文档

规则在较大范围持续生效，Skill 按任务加载。description 应包含明确触发条件和不适用范围；正文描述步骤与产物，详细资料放 references，确定性工作放 scripts。宿主对参数、自动触发和上下文隔离的支持不同，迁移时要检查。

## 任务规划与工作流

计划的价值是暴露依赖与验收点。只有知道现有结构后才能提出可信修改计划，所以先读取代码与规则。失败时退回对应阶段：找错文件回盘点，需求不清回计划，检查不过定位实现，不能一律改 Prompt。

## 可迁移提示与工具差异

自然语言目标可以跨工具使用，运行参数和权限不能。对照时记录版本、模型、输入快照、实际动作与最终结果。保持同一任务卡，才有可比较性；输出格式一致便于比较，但结果形式相同不代表能力相同。

## 复用质量如何评测

至少有触发正例、触发反例、缺资料、格式错误、越界请求。技能修改后重跑这些题。对规则遵守使用程序检查，对内容正确性保留人工核对。不要只展示最成功的一次。
