## B 线：从第四课开始的必修顺序

先确认第三课能解释并运行“模型提出工具调用 → 程序检查并执行 → 结果返回模型”的循环，且有参数检查和最大轮数。第三课是本路线的先修。

每课链接进入本课目录；“课后验收”进入题目与参考答案。下列标准用于判断你的学习成果，项目自带测试通过不等于你已掌握。

### 1. 第四课 · Workflow Graph 与框架【B 线必修】

[打开课程](04-agent-frameworks/index.html) · [课后验收](04-agent-frameworks/lessons/99-exercises.html)

**学习范围**：五项原练习；状态、条件分支、角色交接、暂停恢复和类型约束；动态工作者与两种交接对照。先用一个框架做主实现，其他框架用于比较，不要求全部精通。

**进入第五课前**：

- 能画出流程，解释下一步由程序还是模型决定，以及状态如何更新。
- 用同一任务比较两个框架，保存五项练习的输入、输出与失败分析。
- 完成“生成摘要 → 检查来源 → 人工批准或拒绝”；拒绝不继续，循环有上限，缺来源不能通过。
- 能演示跨进程恢复，并说明保存状态为什么不能自动防止外部动作重复。
- 自己换一个输入或要求，制造并定位一次失败。没有运行的隔离或云端路径单列待验收。

### 2. 第五课 · 工具、规则与 Claude Code 生态【A/B 共用】

[打开课程](05-claude-code-ecosystem/index.html) · [课后验收](05-claude-code-ecosystem/lessons/99-exercises.html)

**学习范围**：B 线理解 5.1–5.7，并完成规则、Skill、Hook、MCP、Subagent 五项原练习。5.1–5.4 是 A 线核心；5.8 Claude Agent SDK 是选修。首次使用宿主时先读本课首次会话章，不必为了 B 线先完成全部 A1–A3。

**进入第六课前**：

- 能分别选择规则、Skill、Hook、MCP、Subagent 和 Plugin，并解释它们的作用范围。
- Skill 能发现缺资料，Hook 日志不保存测试秘密；MCP 合法读取成功，越界请求失败。
- 只读 Subagent 能指出无来源断言，并提供对应证据。
- 能说明规则与权限控制的区别，实际检查所用配置的加载与撤销。程序测试和宿主实际触发分开记录。

### 3. 第六课 · RAG 与 Memory【B 线必修】

[打开课程](06-memory-rag/index.html) · [课后验收](06-memory-rag/lessons/99-exercises.html)

**学习范围**：五项原练习、完整检索回答、记忆生命周期；直接支线里的检索与记忆练习；本地 20 题 A/B/C 对照实验。先完成一套本地实现，不要求安装每一家数据库或记忆产品。

**进入第七课前**：

- 用自己的三份获授权资料完成检索与回答，逐条核对引用是否支持答案。
- 覆盖同义表达、例外、无答案、权限外资料；区分真实 embedding 与字符向量教学基线。
- 保存检索对照结果，能解释改进有效、无收益或退步，不能只展示成功的一题。
- 记忆能跨进程读取、更新、删除；另一用户看不到，旧版本更新会被拒绝。
- 能把失败定位到解析、切分、检索、排序、生成或记忆层，而不是统称“模型不行”。

### 4. 第七课 · 可测、可看、可停、可恢复【B 线必修】

[打开课程](07-multi-agent-production/index.html) · [课后验收](07-multi-agent-production/lessons/99-exercises.html)

**学习范围**：评测、观测、批准与恢复、本地部署四项核心，以及有收据的研究助理。多 Agent 辩论、Streaming 与 Prompt caching 是选修。

**进入第 7.5 课前**：

- 有可重跑的版本化题集、逐题结果和单 Agent 或固定流程基线；完成原 5+3 示例题及综合项目五类控制题。
- 能从一次 trace 定位失败，说明结果是否正确与执行过程是否合规是两种判断。
- 三来源摘要带来源与取得时间；修改产生新版本，批准绑定版本，拒绝不执行。
- 跨进程恢复与重复恢复不重复登记；损坏状态会停止，收据能对应实际产物。
- 本地接口覆盖正常请求、坏输入、模型不可用；不要求公开上线。

### 5. 第 7.5 课 · 是否值得增加复杂度【B 线必修阅读与决策】

[打开课程](07.5-advanced-agentic-concepts/index.html) · [课后验收](07.5-advanced-agentic-concepts/lessons/99-exercises.html)

**学习范围**：评估者—优化者、故障注入、自主权层级、模型与运行设施适配四个核心概念。其他模式按问题选择，不要求全部实现，也不要求购买 API。

**进入第八课前**：提交一份决策记录，包含问题证据、基线表现、唯一拟改动、事前接受标准、停止或撤销方法；完成“保留、简化或移除”的判断。没有真实失败时写待验证假设，可以决定不增加复杂度，不能编造收益。权限与必要审批不能用成本降低来抵消。

### 6. 第八课 · 浏览器、操作界面与隔离【B 线必修；A 线建议】

[打开课程](08-agent-interfaces/index.html) · [课后验收](08-agent-interfaces/lessons/99-exercises.html)

**学习范围**：B 线做练习 1–4；A 线至少做安全打开网页与核对结果的练习 1。实现选择一条合适路线，不需要同时掌握所有浏览器或桌面框架。

**完成 B 线本课的条件**：

- 合法读取能执行；发送等待批准；离域、file URL 和未知动作被阻止。
- 执行前检查页面与批准是否仍有效，执行后重新读取实际结果，保存截图与收据。
- 在隔离环境完成固定 CSV 绘图：输入只读、输出可取回、网络关闭、没有宿主凭证挂载。
- 完整动作循环能处理拒绝、页面变化与执行失败。没有实际运行 Docker 等隔离环境时，隔离练习仍是待验收，不能用本机成功替代。

### 7. 结业 B · 独立完成一个可验证系统【B 线必修】

[打开课程](capstone-b/index.html) · [最终验收](capstone-b/lessons/99-exercises.html)

RAG 或多 Agent 二选一，不为凑架构添加角色。使用自己的获授权资料，运行至少一条真实模型路径并保留工具轨迹；准备 5 个开发题和 3 个新的冻结保留题，基线与候选方案至少三次试跑。人工核对引用、条件、否定和数字，提交失败与回归报告、七维自评及 200 字内反思。从干净环境只靠 README 重跑成功，才算结业；看过答案的示范保留题不能再算自己的盲测。

## 每课怎么学，怎样判断可以继续

1. **理解**：先读主讲义与本地必读讲解，用自己的话说清本课解决的问题。
2. **跟做**：完成分步案例，核对真实输入、输出与执行过程。
3. **补齐**：结合原题读对应补充章，不遗漏本课标为核心的实验。
4. **独立做**：最后进入课后练习，先作答再展开答案，换一个输入或要求重新完成。
5. **排错**：主动制造一次可恢复的失败，定位并修正，保留前后证据。

每课留一份学习记录：做了什么、如何运行、输入与输出、失败原因、修复结果、待补项目。两天后不看答案解释关键区别，一周后换一份资料复做，不要求死记 API 名字。

**必修能力达标后进入下一课；选修未做不阻挡主线。** 缺账户或运行环境时可以先阅读后面的课，也可以开始准备结业选题，但将相关必修实操列为待验收，补齐后才能标记该课及整条路线完成。程序通过、人工内容复核、真实集成和独立掌握分别记录；NEEDS_REVIEW 不是自动通过。

## 大概需要多少小时

这是针对当前本地课程和你已学到第三课的情况做的**学习规划估算，不是实测平均时长或保证**。只计算第四课起的 B 线；不重算第二、三课。

“阅读理解”指阅读主讲义、本地必读讲解并看懂核心代码，不含实际完成练习，不要求逐字读完所有参考目录和选修代码。“完整学习”已经包含阅读，再加亲手运行、独立修改、排错、验收与结业项目；两列不要相加。

| B 线阶段 | 阅读理解 | 完整学习，含阅读与核心实作 |
|---|---:|---:|
| 第四课 | 6–8 小时 | 16–22 小时 |
| 第五课 | 5–7 小时 | 12–18 小时 |
| 第六课 | 8–11 小时 | 24–34 小时 |
| 第七课 | 7–10 小时 | 22–32 小时 |
| 第 7.5 课 | 2–3 小时 | 4–6 小时 |
| 第八课 | 4–6 小时 | 12–18 小时 |
| 结业 B | 1–2 小时阅读任务与示例 | 18–30 小时 |
| **合计** | **33–47 小时** | **108–160 小时** |

按每天 1 小时，阅读约 5–7 周；按每周 8 小时完成练习与结业，约 14–20 周。若 Python、终端和环境排错仍不熟，完整学习额外预留约 20% 时间。下载模型、等待外部账户或远端审批的被动等待不计入上述专注学习时间。

额外选择 A 线时，A1 约 4–6 小时、A2 约 6–10 小时、A3 约 8–12 小时、结业 A 约 8–14 小时，合计增加约 **26–42 小时**；已在 B 线完成的第五、八课不重复计时。身份分支的首次完整任务每条约 **3–6 小时**；选修框架深挖和公开部署没有统一上限，不算进主线总量。

先完成第四课再用实际投入校准后面的估算。进度以能完成验收为准，不以看完页面数量为准。
