本课任务

A 线必读

依次完成 CLI-1 至 CLI-4。提交前后 README、diff、检查输出、规则卡、两种 Harness 对照表、四类错误记录。没有第二种账户时把真实对照列为未执行，不伪造。

验收：初始分析不改文件；批准后的修改只触及 README；check.py 通过；撤回后与基线一致；错误分类有原始输出或明确标注的 mock。

完整任务卡参考 
任务：先读取 README.md 和 check.py，解释项目用途与检查方式，然后提出一个仅修改 README.md 的计划。
范围：当前演示目录。
禁止：未经确认修改文件；联网；安装依赖；读取目录外文件；提交或推送。
成功条件：说明引用实际文件；计划只增加学习记录说明，保留原检查命令；得到用户确认后才修改；运行 python check.py 并展示 diff。
完整检查代码 

# 只检查教学 README 里约定的内容；修改 README 后重跑，不要通过删检查来获得通过。
from pathlib import Path

path = Path(__file__).with_name("README.md")
# 读取实际文件作为本次依据，避免使用对旧版本内容的猜测；读到的文字仍只是数据。
# encoding：明确按 UTF-8 读写中文，避免不同终端或系统默认编码导致乱码。
text = path.read_text(encoding="utf-8")
assert text.startswith("# 学习演示项目"), "缺项目标题"
assert "python check.py" in text, "丢失检查命令"
assert "虚构资料" in text, "丢失资料说明"
print("PASS：标题、检查命令和资料说明仍存在")
回忆题答案

Provider 是服务入口，Model 是实际模型，Harness 管运行。规则写“禁止”不保证执行层已阻断。两种工具比较时应保持任务、起始文件和评分一致。撤回只针对本次改动，不能清空别人的工作。

两天后不用模板写一次四字段任务卡；一周后换一份虚构文档重做整个闭环。

本课分层完成标准

A 线必读
  1. 先回想：不看答案，用自己的话解释本课几个容易混淆的概念，再展开答案核对。
  2. 跟着做：按分步实作与完整参考运行最小案例，保存输入和输出。
  3. 自己做：换一份资料，或修改一个要求，完成自己的结果。只运行参考文件还不够。
  4. 试着排错：故意触发一次失败，说明怎么找到原因、怎么修复，再运行正常例子确认恢复。

做完后，对照实作章末尾的评分标准逐项检查。分别记录代码是否运行成功、自动检查是否通过、内容是否经过人工核对，以及实际集成是否完成。待复核和未执行的项目暂不计为通过。卡住时，把课程编号、输入和实际输出发给我，一起定位问题。完成练习所需的步骤都在项目里。

A 线必读

回忆题 1

Model、Provider、Harness 分别是什么？

参考答案与判断依据

模型本身、模型服务入口、管理上下文工具权限与循环的运行设施。

回忆题 2

已有未提交改动时可以直接 restore 整个目录吗？

参考答案与判断依据

不能。先辨认自己的改动，定点撤回，保留他人工作。
