# A1 必修入口的本地说明

## 各 CLI 官方入门共同解决的问题

安装得到可执行程序；认证让程序获得服务访问；选择目录决定工作上下文；权限设置决定能执行什么；任务指令决定做什么。每一步都能独立失败。查看版本和 help 是确认实际安装行为的方法，不能拿另一产品的命令套用。

Claude Code、Codex、Gemini CLI、GitHub Copilot CLI 等可能连接不同账户与模型服务；OpenCode、Pi、Aider 等在 provider、编辑方式和上下文管理上有不同取舍。免费额度、支持模型和操作系统属于易变信息，学习本课不依赖任何永久免费的承诺。

## 规则、上下文与执行边界

规则文件应简短、具体、可验证。说明“只修改 README，运行 check.py，返回 diff 与结果”比“请专业地处理”可检查。文档内的代码或提示属于资料，不能自动变成用户授权。只读任务不需要开启任意写入和网络。

## Git 的最低知识

Working tree 是当前文件，staging area 是将要提交的集合，commit 是一个版本。diff 显示两个状态的差异。撤回时只处理本次明确改动；git reset --hard 会影响整个工作目录，不应作为初学者的通用修复命令。在干净 demo 中先保存基线再实验，能把回滚范围看清楚。

## 四字段任务卡

任务写目标，范围写允许资料和目录，禁止写不应发生的动作，成功条件写可观察结果。它可以跨工具迁移；不同工具的规则位置、权限菜单、登录和模型设置则放在差异卡里。这就是下一课 portable prompt 的基础。
