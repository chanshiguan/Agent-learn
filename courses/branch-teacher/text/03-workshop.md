# 完整教案、事实核查与形成性评价

## 单元一：对齐原题，再增加迁移

原题是小学高年级、15分钟、影子变长变短、纸笔手电筒；要求目标、两层提示、一题形成性检查、两道离堂题、三条科学事实核查。完整答案的 original_activity 保留这些条件。影子大小与卡片位置的草稿作为迁移活动，不能取代原题。

学习目标要能观察：“说明改变哪个变量，用两次描线支持结论”，比“理解影子”可验收。形成性检查在活动中用来决定是否重教；exit ticket 在离开前独立做，不能只是抄教师刚刚展示的答案。提示从小线索到具体观察办法，保留学生自己推断结论。

## 单元三：三份必读材料在本课怎样落地

UNESCO 的人本框架同时讨论生成机制、争议、治理责任、教育政策、潜在教学研究用途和未来问题。生成文本不理解真实课堂全部情况，可能放大偏见、同质化与数字鸿沟。教学应用是需要验证的可能性，不是已经证明对每个学生有效。把独立思考、实物观察与同伴讨论保留在活动里，不用自动生成替代全部学习。

欧盟指南从监督、透明、公平、社会环境影响、隐私、可靠性和问责检查具体场景。应用到本题：教师审核事实与提示；说明 AI 参与草拟；提供不依赖个人设备的活动；不上传真实学生表现；错误材料可纠正并能找到责任人。选工具、试点、收集反馈、复核效果应成为连续流程，而非一次签字。指南不是替学校解释当地全部法律。

TeachAI 七个原则分别强调目的、合规、知识、平衡、诚信、自主权、评估。落实成班级规则：本次可用 AI 帮教师列备课草稿；学生两道离堂题独立完成；若用 AI 辅助作品则说明用途；不能用文本检测器直接判作弊。规则还应与学校和家长沟通，并根据真实反馈修订，不能将网上范本直接当本校政策。

这三套框架解决不同层次：为什么和为谁使用、怎样检查责任与风险、怎样转成课堂规则。都不授权用模型独立决定成绩、纪律或特殊教育判断。

## 单元四：怎样评分而不把人贴标签

对作品中的可观察证据评分：是否控制变量、是否有比较记录、解释是否保留条件。不要根据一句话推断学生智力、家庭或健康。分组名称用“需要变量控制支持”，不用“差生”。反馈应指向下一步动作，例如固定纸条重新试，而不是只说“再努力”。

为同一道题准备不同水平的虚构答案，先由教师独立评分，再对照评分标准检查模型建议。相近内容换一种表述，模型分数就明显变化时，应先调整评分标准，或暂停自动评分。学生作品用于真实工具前按学校规则处理，课程练习只用虚构材料。

## 课末提交与验收

请提交自己的完整教案、四级评分标准，以及对三份虚构作答的反馈：

```bash
# 运行 courses/branch-teacher/examples/check_work.py，按本行参数完成当前案例并核对输出。
.venv/bin/python courses/branch-teacher/examples/check_work.py /tmp/teacher-work.json
```

结构检查不会把教案判为科学正确。人工验收六项必须全部满足：15分钟可执行；材料满足题目；目标与两题对应；提示不直接泄题；三事实有核查方法与边界；反馈能指导下一步且不使用真实学生数据。参考教案缺少的实际班级信息须在上课前确认，不编造。

两天后只看离堂题反推学习目标；一周后用三份虚构结果调整一条提示，再解释为何改变。这样测的是教学设计能力，不是运行一份 JSON 的能力。
