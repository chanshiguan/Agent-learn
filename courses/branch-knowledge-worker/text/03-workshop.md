## 单元三：连接器的完整工作过程

手工贴一段授权资料适合一次性任务。重复需要搜索组织文件时，再由组织允许的连接器接入。连接包含身份授权、内容可见范围、同步或实时检索、引用与更新。ChatGPT Apps、Claude 连接目录、Gemini Connected Apps 与 Copilot connectors 的入口不同，但都要核对已有权限、管理员设置、所需许可和来源时效，不能从“连接成功”推导“能读所有资料”。

查不到资料按顺序检查：能否在原系统直接打开；项目/标题/日期是否限定清楚；连接器是否启用；索引是否已同步。找不到就报告，不能凭模型记忆补组织事实。撤销连接不一定自动删除先前保存的摘要，需检查副本。

MCP Registry 提供服务器发现与元数据，不替每个程序做可信认证。只有确需自定义或跨客户端连接才加 MCP，简单会议整理不用额外部署服务器。

## 单元四：自动化为何需要人工关卡

Zapier、Make、n8n、Power Automate 等流程通常由 trigger 启动，然后做字段映射和一个或多个 action。先用虚构样本逐步测试：读取消息 → 生成表格草稿 → 验证字段和来源 → 人审 → 才考虑写入。没有通过人审时，只保存草稿。

重复事件需要唯一事件 ID，避免同一消息写两次；写回原系统可能再次触发自己，必须排除自发事件或限制循环。失败要能指出在哪一步和如何重试，不把整个链从头无条件再执行。自托管只说明运行平台在自己控制下；模型、embedding 或连接器仍可能把资料发到其他服务。
