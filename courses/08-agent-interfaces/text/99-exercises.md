1. 打开 example.com，核对标题与最终地址，截图后停止。
2. 验证合法只读 ALLOW、发送 ASK、恶意后缀域 BLOCK、file URL BLOCK、未知动作 BLOCK。再测大小写、userinfo 与异常端口。
3. 使用只读输入和独立输出目录运行固定 CSV 绘图。证明没有宿主凭证挂载、网络关闭、输出可取回；未安装 Docker 时记录为未执行，不把本机运行当容器验证。
4. 运行完整动作链，故意提出离域请求与发送请求，确认没有执行；允许的读取能产生观察和截图。

## 回忆、排错和迁移

解释为什么 ASK 不能直接继续，为什么截图旧了不能沿用坐标，为什么 Container 与 VM 不是同义词。把 allowlist 改为另一个测试域时同步改测试；不要临时把所有域都放开来“解决”失败。两天后只看收据判断哪些动作实际执行；一周后为本地虚构表单增加一个只填写不提交的动作，再编写边界测试。

## 本课分层完成标准

1. 先回想：不看答案，用自己的话解释本课几个容易混淆的概念，再展开答案核对。
2. 跟着做：按[分步实作与完整参考](03-workshop.md)运行最小案例，保存输入和输出。
3. 自己做：换一份资料，或修改一个要求，完成自己的结果。只运行参考文件还不够。
4. 试着排错：故意触发一次失败，说明怎么找到原因、怎么修复，再运行正常例子确认恢复。

做完后，对照实作章末尾的评分标准逐项检查。分别记录代码是否运行成功、自动检查是否通过、内容是否经过人工核对，以及实际集成是否完成。待复核和未执行的项目暂不计为通过。卡住时，把课程编号、输入和实际输出发给我，一起定位问题。完成练习所需的步骤都在项目里。
