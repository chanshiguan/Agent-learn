# 《狂人日记》公开教学样本

这五篇是为名著伴读开发课程重新编写的阅读材料，供学生、家长和开发者练习有据问答。正文保留叙述视角、平等、伤害、反省与未来等讨论主题，重新组织论证和例子，不收录私人授课录音的转写稿。它们不是鲁迅的作品全文，也不是某位教师的原讲义。

## 来源与解释边界

小说细节和短引句依据[维基文库《狂人日记》的固定版本](https://zh.wikisource.org/w/index.php?title=狂人日記&oldid=2605391)核对，查阅于 2026-11-10。原作作者为鲁迅；本课程引句按简体转写，其他讲解为课程新编。固定网页用于复核文字，不代表已经建立纸质版本的页码映射。

“月光与平等”被标为一种可讨论的读法；“已经恢复”是序言中的转述；不把小说当成独立史料，不根据人物为现实中的人作疾病诊断。题目沿用“徐锡麟”，核对文本中的写法为“徐锡林”，第三讲专门说明差异。

讲次、Word 段落 ID 和原著节号是三套不同标记。样本没有提供准确纸质页码或出版社对应表，因此两道证据不足题仍应说明资料缺失，不能猜页码。讲解中提到的原著节号也不等于防剧透范围已经人工审核。

## 文件如何进入课程

Markdown 是可编辑的正文源。练习目录中的 `prepare_samples.py` 从它们生成五份 DOCX 和一份来源清单。为了保留“长段落为什么需要切块”的实验，每份 DOCX 使用一个正文段落，段内保留换行；这是一项明确的教学存储选择。

生成脚本清空个人作者、上次修改者等属性，并固定时间和 ZIP 条目时间；同一份源文本可以重复生成相同字节。它检查已有输入，遇到不同内容会停止，不覆盖学习者修改的文件。DOCX 是本课程的新样本，不继承私人文件的元数据。

[题目与参考答案](answers.md)供人工核对，不进入检索库。开发题和保留题的题干、ID、目标讲次及无答案设计均保持不变；只更新新讲稿中的证据短句。六题只用于教学，不能充当真实公司完整质量验收。

公开课程目录只包含这批新编样本。真实公司的知识库、学生信息、聊天记录、密钥和生成的数据库仍放在本地数据目录。重新发布时须检查实际打包内容；公开代码不等于应当公开业务数据。
