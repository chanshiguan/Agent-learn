# 发布证据包

本目录是待填写的工作材料，不包含任何真实公司的批准。

每次候选发布复制一份 acceptance.json，给出目标读者、允许的试用人数和并发。质量阈值由题集与人工量表定义；延迟、费用、恢复目标必须由负责人确认，不能沿用教程里的示例数字。

证据字段写可访问的报告路径、版本和运行日期。负责人字段写真实审核人；由本人确认后再登记结论。known_blockers 保留未关闭问题。decision 只在对应审核完成后改为 trial_approved 或 release_approved；它只是记录，不会部署任何服务。

发布前执行自动测试、生成 manifest、冻结实际依赖和镜像摘要，重新跑保留题及权限、恢复实验。公司环境还要决定身份系统、内容授权、未成年人使用规则、隐私告知、数据留存、监控告警与值班。课程中的最小账号系统不是这些决策的替代品。

应用回滚：停止入口流量，保留故障证据，启动上一个已经验证的镜像标签，配套恢复上一版 Prompt 与 corpus/index 指针。数据结构不兼容时，按第 28 章的恢复演练执行，不盲目覆盖正在写入的数据库。

删除请求与备份：记录删除的主体与时间；恢复旧备份后先重放未过留存期的删除清单，再开放访问。备份到期删除与访问审计由公司存储流程执行，本课程脚本不自动操作公司备份。
