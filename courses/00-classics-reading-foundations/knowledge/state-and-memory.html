对话、记忆与流程状态有什么区别

预计 8—10 分钟不计入主线验收无需额外安装

这是独立选读。读懂一个概念就可以返回主线，不要求另装服务或完成额外作业。

先分清保存的目的

内容 用来做什么 典型边界
知识库片段 回答时找到有来源的资料 作品、版本、资料权限
最近对话 理解这次阅读的上下文 本人、长度、删除与进度变化
显式阅读进度 记录读者明确选择的范围 可查看、修正，不从闲聊猜测
批准动作 记住待确认内容与执行状态 版本、有效期、幂等
图检查点 恢复流程停在哪一步 线程归属、恢复时再核验权限

它们都能存进数据库，却不因此变成同一种“记忆”。把全部对话永久拼进 Prompt，会增加成本，也可能把旧范围之外的剧情带回回答。

在伴读项目里怎么选

先保存明确需要的最小状态。最近两轮帮助接话，进度由读者选择，笔记由本人确认。长期偏好只有在产品确实需要、读者知道且能修改时再增加。图检查点还可能含草稿，个人数据删除不能只清 notes 表。

继续读哪一段

先读 Hello-Agents 第八章 的记忆与检索职责，再读 第九章 的上下文组织。想理解暂停与继续，可看 LangGraph interrupt 官方说明，重点看检查点、thread_id 与恢复节点。框架保存位置，不代替业务批准。
