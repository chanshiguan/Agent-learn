请求经过哪些地方

浏览器 → 业务 API → 身份与输入检查 → 检索/模型 → 状态提交 → 浏览器。页面只知道业务地址，模型凭据留在服务端。返回的数据按文字显示，不把模型内容当可执行 HTML。

三种检查不能混为一谈

检查 回答的问题 伴读例子
输入校验 字段和范围是否符合约定 问题最多 800 字符，不接收额外 owner
认证 你是谁 登录后验证短期令牌
授权 你能做什么 只能读取本人的会话与笔记

隐藏按钮、难猜的 ID 和前端字段校验都不能替代服务端授权。测试身份是本机练习工具，不是可以直接交给公司的账号方案。

进一步了解
