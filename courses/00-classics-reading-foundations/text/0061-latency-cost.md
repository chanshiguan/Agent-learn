## 两种数字不能互相代替

elapsed 是等待多久，token usage 是模型接口报告的输入/输出用量。线上费用还取决于实际服务的计费规则；本地模型没有同样的 API 账单，但仍消耗设备时间和内存。缺失 usage 就标未知，不能填 0 冒充免费。

选一次普通 RAG 和一次 Agent 请求，在 Network 响应里分别记录模型用量。Agent 的 usage 是多次调用列表，要累计每一轮，不能只看最后的答案。重排与查询改写也会增加额外调用。

做一张表：方法、资料 revision、输入字符数、模型调用次数、输入 token、输出 token、总耗时、费用依据。费率使用你实际服务当时的账单或正式报价，不在课程里写一个永久有效的价格。

## 做一个小而可解释的优化
