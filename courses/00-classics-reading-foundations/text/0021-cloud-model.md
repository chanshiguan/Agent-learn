# 线上路线 把服务地址和凭据配置清楚

本单元预计 **20—30 分钟**，开通账号和申请凭据的等待时间另计。第 4 章线上路线共 **70—105 分钟**。已经选本地路线的学员可以跳过；想比较两条路线，可以在本地跑通后回来做。

## 选择本章能直接连接的接口

本章使用 Chat Completions 兼容接口，也就是 Python 程序能调用 `client.chat.completions.create` 的服务。供应商需要提供服务地址、准确模型标识和 API key。仅有网页聊天账号，未必就有 API 访问权限。

本阶段先选择一种兼容服务。若供应商只提供自己的原生协议，不能保证改地址就能运行；以后需要在模型调用部分增加对应实现。我们不会为连接第一个模型同时教多套 SDK。

在供应商控制台准备三项信息：接口的基础地址、开通的模型名、密钥。地址应包含供应商要求的 API 前缀，但不要填完整的 `/chat/completions` 路径，因为客户端会追加它。

## 输入配置，不把密钥写进代码

在实际学习电脑的终端执行下面这组命令。每次提示后输入对应的真实值，按回车继续。输入路径或模型名时不用额外加引号。

```bash
# 让共用程序启用线上连接检查；后续需要 HTTPS 地址与真实密钥。
export LLM_MODE=cloud
# 在终端显示输入提示或换行；这一步不读取资料，也不发送网络请求。
printf '请输入兼容接口基础地址（HTTPS）：'
# 把你随后输入的一整行保存到变量；输入真实值后按回车，路径不用另加引号。
read -r LLM_BASE_URL
# 在终端显示输入提示或换行；这一步不读取资料，也不发送网络请求。
printf '请输入账号已开通的模型名：'
# 把你随后输入的一整行保存到变量；输入真实值后按回车，路径不用另加引号。
read -r LLM_MODEL
# 在终端显示输入提示或换行；这一步不读取资料，也不发送网络请求。
printf '请输入 API key（输入不回显）：'
# 接收密钥但不回显；预期输入后屏幕不显示密钥文字，按回车结束。
read -r -s LLM_API_KEY
# 在终端显示输入提示或换行；这一步不读取资料，也不发送网络请求。
printf '\n'
# 将刚输入的配置传给后续 Python 进程；不打印密钥，也不把它保存到代码中。
export LLM_BASE_URL LLM_MODEL LLM_API_KEY
# 清除其他实验留下的专用推理参数，减少当前模型因不支持该参数而报错的可能。
unset LLM_REASONING_EFFORT
```

`read -s` 不把输入显示在屏幕上；密钥也没有被写进脚本或命令参数。`export` 让后面启动的 Python 进程可以读取变量。不要把密钥截图、发进聊天或提交到 Git。

## 确认这次会发送什么

共用程序只发送一个关于《狂人日记》的短问题，不读取 `data/input/`，也不会上传整套讲稿。后面要把讲稿放进线上请求时，再明确资料可用范围和发送内容。

先在账号中设置适合自己的小额预算或额度提醒，只运行一次验证。程序关闭自动重试，便于你把一次命令与一次请求对应起来。返回的 token 用量可用于估算费用，但没有实际单价就不能从 token 数直接得到金额。

## 常见配置错误

| 现象 | 先查什么 |
|---|---|
| HTTP 401 或 403 | 密钥、账号权限及模型开通状态 |
| HTTP 404 | 基础地址是否填错，模型标识是否存在；具体含义也看服务返回规则 |
| HTTP 429 | 额度或请求限制；先确认原因，不连续重试 |
| HTTP 400 | 请求参数或接口能力不匹配，尤其是误带其他模型的专用参数 |
| 连接失败或超时 | 地址、网络、代理与服务可用性 |

状态码用来缩小范围，不替代服务方的具体错误说明。需要排错时，只分享去掉凭据的错误与配置形状。

**本单元完成条件：**三项配置已由你输入，并且知道随后会发送的内容。实际调用在下一单元完成；没有付费账号时，本地路线仍可继续。

**需要哪三项配置？** 兼容接口的 HTTPS 基础地址、账号已开通的模型标识、真实 API key。基础地址不包含客户端会追加的 `/chat/completions`。

**这次会发什么？** 共用程序发送 system 要求和一个公开阅读问题，不读取或发送五份讲稿。看到文学回答并不能证明服务访问过知识库。

**配置报错怎样判断？** 401/403 先查凭据与权限；404 查地址或模型；429 查额度或限流；400 查参数支持；连接错误查网络和服务。仍须结合供应商具体错误，不只凭数字猜测。

**通过证据：**三项配置已在自己的终端输入，能说明请求内容和预算限制；记录模型名及不含密钥的地址即可。不要把真实密钥写进验收记录。配置完成还不是调用成功，下一单元再验证。
