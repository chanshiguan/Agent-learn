# 先预览一份笔记，确认后再保存

本单元预计 **35—50 分钟**。本章总用时见课程地图；首次安装、模型下载和等待他人审核另计。

## 写入与查询的风险不同

读错一条资料可以重查，写错笔记会影响以后阅读。模型先产出草稿，页面展示具体内容；读者确认当前版本后才保存。复习计划同样只是草稿，不自动改日历、发送消息或改变阅读进度。

```bash
# 停止旧服务后显示笔记区；仍沿用现有会话与资料。
export COURSE_CHAPTER=19
python -m uvicorn companion.app:app --host 127.0.0.1 --port 8000
```

先完成一轮普通有据问答，再点“生成笔记草稿”。读完内容，修改一个不准确表达，点“保存修改，重新预览”。只有新预览正确时再点“确认保存这一版”。受限模式不从对话自动生成草稿，避免重新引入范围外内容。

## 暂不依赖模型，单独练写入协议

```bash
# 创建一份教师拟写的练习草稿，测试批准逻辑；这不是模型生成结果。
python -m companion action draft --text "我会回查讲稿中序言与日记的关系，并区分讲解观点和原著引文。"
# 列出本人的草稿 ID，便于选择要确认的那一份。
python -m companion action list
# 交互输入草稿 ID，看到完整内容后输入 YES 才保存；其他输入不批准。
python -m companion action approve
# 检查已保存笔记，预期出现刚才明确确认的内容。
python -m companion action notes
```

命令行练习使用测试身份，正式服务的身份由登录决定。不要把通用的“你可以保存笔记”理解为对以后任何内容都批准；确认应绑定当时看到的具体版本。

<details class="answer-key"><summary>查看参考答案与通过标准</summary>

**为什么修改后必须重新预览？**

旧批准针对旧内容。修改改变了语义和摘要，新版本需要新的明确确认。

**确认复习计划会自动修改进度吗？**

不会。本课程只把确认后的计划作为本人笔记保存，进度由读者单独明确设置。

**通过证据：**一份真实模型草稿、一份修改后确认的笔记和未批准时没有写入的记录。
