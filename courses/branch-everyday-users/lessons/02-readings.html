官方产品入门的共同原则

身份分支选读

明确任务、提供必要背景、指定输出、保留核对步骤。模型可能补全不存在的信息，所以日期、金额、地点、身份和实际执行状态尤其需要检查。要求“不要出错”不能保证准确。

工具、连接器与 Agent

身份分支选读

工具让程序查资料或做动作，连接器把账户或服务接进来，Agent 在这些能力上选择下一步。授权某个工具不能推导为授权所有行为。确认对象、内容、范围和时间后再执行，执行后读取真实结果。

自动化与记忆

身份分支选读

重复流程应有触发条件、输入检查、动作范围、失败通知、停止开关和收据。记忆应能查看、纠正、删除；系统承诺“记住了”不等于已经可靠持久化，“忘了”也不等于所有副本都已删。

Browser / Computer Use

身份分支选读

网页内容可能包含恶意指令。不要让页面文字改变用户授权，敏感动作再次检查。使用专门测试环境，不在教学中登录真实付款或私密账户。第八课本地资料提供完整策略与执行循环。
