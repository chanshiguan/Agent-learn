## 实验结论与教学质量复核

54 项回归测试通过；218 页、5626 条本地引用、108 个 Python 案例的语法和完整展示通过；新增五章与16课来源表共21页经过桌面及手机宽度检查。静态检查和测试证明对应范围内的行为，不单独证明全文教学完整或学习者掌握。

20 题实验的三组平均 Recall@5 都为1，A 的 MRR约0.972、B/C为1，C没有额外平均收益；两条应空结果题中一条仍误检。本教材没有把这些结果修饰成“重排一定提升”或“系统已可靠”。参考答案明确区分实验完成与系统质量，并要求解释失败、保留负结果和准备新题。

真实本地模型运行中，manager-as-tools 最终由 manager 回答，handoff 最终由 specialist 回答，日期正确，事件符合控制流程。主管把来源写成工具名而非 signup 文档 ID，内容引用仍需改进，未将其报告为来源质量验收全部通过。该问题用于说明控制流程正确与来源表达正确是两项检查。

SDK 默认 demo 的会话 ID 为 null，不能伪装真实可恢复会话；成功消息也只标 NEEDS_REVIEW。限制与超时返回失败状态。实际 SDK options 验证了工具列表为空、MCP 配置受限、轮数与恢复 ID。

教材保护检查发现此前 Finder 的 .DS_Store 变化，这是系统目录元数据，已从内容保护断言中排除。第二、三课的教材内容与本轮保护快照一致，未替他人撤回同步修改。
