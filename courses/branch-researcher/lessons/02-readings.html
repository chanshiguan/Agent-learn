原论文与可重复研究

身份分支选读

Attention Is All You Need 的重点是用注意力构造序列转换架构。Encoder/decoder、位置表示、注意力和前馈层分别承担不同职责；去掉循环不等于完全不需要位置信息。实验结论依赖论文里的任务与设置，不能无限外推。研究阅读要把方法、实验和作者解释分开。

可重复记录的核心是让另一个人知道用哪份数据、哪段代码、哪些参数得到哪个产物。失败实验也保留，避免只展示最佳一次。数据不可公开时应说明限制、可提供的复现材料和替代验证方式。

检索、引用管理与实验工具

身份分支选读

学术搜索发现候选；文献管理器维护元数据和阅读记录；检索增强工具帮助按问题取片段；实验跟踪器记录配置与指标；数据版本工具记录数据变化。它们不会自动替你判断论文是否可靠。

DVC 的工作思路是把大数据与 Git 中的轻量元数据分开，记录来源和管线依赖，数据变化触发相关步骤重跑。记录工具只说明“做过什么”，不是结果正确性证明。

论文发现、全文阅读、跨文档问答、代码实验、科学 Agent 属于不同阶段。先找自己真正卡住的一步；对自动研究系统检查有没有来源定位、方法可解释性、可重复实验和人工检查入口。原课程的全部候选与用途已留在本地资料中，不要求把每个项目都部署一次。
