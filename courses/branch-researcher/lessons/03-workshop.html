单元二：引用的三步核对

身份分支选读

第一步列断言，一句话包含两个事实就拆开。第二步找到能支持它的段落位置；标题相关但内容不支持，不能算引用。第三步核对范围：作者报告的结果、作者的解释、你自己的推断分别标注。

例如“翻译任务有效”不能扩成“所有任务有效”。两个论文用不同任务、数据切分或指标时，不直接比较数字。没有找到作者的明确限制段落，应写你的证据范围判断，不能编造“作者承认……”的引语。

单元四：文献工具的操作知识

身份分支选读

带引用的 Notebook 流程是导入获授权来源 → 按问题检索 → 打开引用 → 同时读上下文 → 把支持或不支持写回笔记。引用只是入口，点击后没有支持仍要退回。上传前确认资料许可和工具数据处理范围；公开可读不自动授权转交任何服务。

Zotero 中条目存作者、年份、题名、出版信息，附件存 PDF，笔记存你的阅读判断。先核对元数据，再用 collection 按项目组织、tag 标阅读状态，重复条目先合并，最后生成引用与书目。同步条目与同步附件不是同一件事；引用格式正确不等于内容正确。

可重复研究要版本化代码、数据、参数与结果。DVC 用小元数据文件在 Git 中记录大文件版本，大文件另进 cache/remote；dvc add 不等于把数据上传远端。恢复版本要匹配代码与数据，管线明确依赖、命令和输出。MLflow 等记录参数、指标与产物，不能替你判断科学结论。Zenodo 发布要补标题、作者、版本、许可和数据说明；上传之后才有可追溯发布记录，课堂不要求实际公开。

PaperQA 等将检索和证据摘要接到答案；ASReview 帮助筛选候选文献，纳排理由仍需记录；repo2docker 从环境声明重建运行环境，不保证数据可访问或结果复现。自动研究 Agent 尤其应保留失败实验，不能只汇报最好的随机种子。
