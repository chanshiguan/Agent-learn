Stage 03 · Tool Use & Hello Agent

工具使用与
第一个 Agent Loop

让模型提出请求，让 Python 安全执行，再根据结果继续。沿用你现有的 Ollama 环境，写出不依赖框架、能测试、会停止的第一个 Agent。

直接在本项目学习。讲解、三份必修阅读的中文知识整理、完整代码、测试、参考速查与课后练习全部在这里。无需回原始网站完成学习步骤。

开始前，你需要能运行 Python，认识函数、list 和 dict，并学过第二课的 Prompt 内容。主线使用 Ollama + gemma4:e4b，第三课单独存放，不覆盖第二课。

扩展选读（单元9–15）：流式、工具选择、真正并发、ReAct研究与检索、Self-Refine/Reflexion、Instructor/Outlines、CodeAct及对应练习。需要这些能力时再学，每个案例均有完整代码。

主线必读B 线基础必修

单元 1–8 是主线必读与必做；单元 9–15 为扩展选读、选做。ReAct 的基础必读内容已在单元 7 整理。

按顺序学习

  1. 主线必读学习地图与运行环境分清谁提出请求、谁执行代码；准备可验证的环境。
  2. 主线必读工具接口与参数验证读懂 Schema，理解它与函数实现、权限检查的边界。
  3. 主线必读单工具的完整往返运行第一个案例，逐条检查消息历史。
  4. 主线必读多工具与第一个 Agent Loop让模型根据观察继续行动，完成有依赖的多步骤任务。
  5. 主线必读错误恢复与执行边界处理坏参数、未知工具、失败请求和无限循环。
  6. 主线必读Schema 对比与固定评测用实际轨迹和明确标准比较两种工具说明。
  7. 主线必读三份必修阅读与协议对照在本地读完必要知识；运行结构化输出与 Anthropic 案例。
  8. 主线必读基础练习与综合项目先完成主线验收，再按需选择单元9–15的扩展内容。
  9. 扩展选读流式工具调用把分片参数组装完整，验证完成后再执行。
  10. 扩展选读工具选择控制与并发执行控制模型何时调用工具，正确关联并发结果。
  11. 扩展选读ReAct论文详解与检索实验理解研究方法、对照实验和失败类型，跑通两跳查询。
  12. 扩展选读Self-Refine与Reflexion让反馈能修正输出、形成可复用经验，同时防止越改越错。
  13. 扩展选读Instructor与Outlines完整实战区分类型校验、失败重试与生成约束，运行同一抽取任务。
  14. 扩展选读CodeAct与代码执行边界用代码组合工具，在受限解释器中观察执行反馈。
  15. 扩展选读补充课后练习与综合验收闭卷解释、运行新案例，用证据检验全部补充内容。
