执行前检查

  1. 请求结构合法，有唯一 ID。
  2. 函数在本次授权的工具列表中。
  3. 参数能解析为对象，字段无缺失或额外。
  4. 字符串、枚举、数值类型与范围合法。
  5. 当前身份拥有操作权限，且操作符合业务规则。
  6. 次数、时间与消耗检查允许继续。
