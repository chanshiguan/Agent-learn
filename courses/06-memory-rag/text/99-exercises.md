# 第六课课后练习

## 目的、成果与材料

目的：分别证明检索有效、回答受证据支持、记忆生命周期正确。准备三份自己编写的虚构资料：课程时间、报名规则、退款例外。不要使用个人或公司的真实敏感资料。

提交 docs/、至少八个问答案例、检索排名表、带引用回答、记忆生命周期日志和一页报告。能力目标是能指出失败发生在切分、检索、排序、生成还是记忆层。

## 原练习 1–5

1. 用真实 embedding 比较同义、相反和无关句，记录模型与维度。
2. 把片段放入 Chroma，查一个确实有答案的问题和一个无答案的问题。
3. 比较固定长度、段落、标题三种切分，记录断开的关键例外。
4. 运行完整 RAG，要求每条事实指向返回的 chunk ID；无证据必须说明。
5. 保存“先短后长”，读取、改成“分步解释”、删除，并检查另一个用户看不到。

每题完整原代码与测试在 examples/upstream 的同编号目录。做完原练习 5，再运行下面补充程序验证真正重启读取；不能用进程内变量证明持久化。

## 综合练习：有证据、可遗忘的助手

沿用三份资料，先做纯向量 baseline，再只增加混合检索或重排其中一项。至少包含“例外条款”“不存在答案”“同义表达”“权限外资料”四类问题。对比 Hit@k、Recall@k、引用支持性和耗时；改进无收益也要如实报告。

验收：无资料不编造；来源 ID 都在本次候选；不能引用其他用户资料；关闭存储后重新打开仍可读取；删除后返回 None；旧版本更新被拒绝。教学回答模板不能算真实生成模型的成绩。

## 本课分层完成标准

1. 先回想：不看答案，用自己的话解释本课几个容易混淆的概念，再展开答案核对。
2. 跟着做：按[分步实作与完整参考](03-workshop.md)运行最小案例，保存输入和输出。
3. 自己做：换一份资料，或修改一个要求，完成自己的结果。只运行参考文件还不够。
4. 试着排错：故意触发一次失败，说明怎么找到原因、怎么修复，再运行正常例子确认恢复。

做完后，对照实作章末尾的评分标准逐项检查。分别记录代码是否运行成功、自动检查是否通过、内容是否经过人工核对，以及实际集成是否完成。待复核和未执行的项目暂不计为通过。卡住时，把课程编号、输入和实际输出发给我，一起定位问题。完成练习所需的步骤都在项目里。
