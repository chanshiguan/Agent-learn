# Triage 标签

相关技能使用五种标准 triage 角色。本文件将这些角色映射到本仓库工单系统实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库使用的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此工单 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交由 AFK agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色时（例如“应用 AFK-ready triage 标签”），使用表中对应的本仓库标签字符串。

如果本仓库日后采用其他标签词汇，可直接编辑右侧一列。
