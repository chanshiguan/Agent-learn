本单元 25—40 分钟本章 本地 75—115 分钟 / 线上 70—105 分钟安装与下载等待另计选读不计入用时

本单元预计 25—40 分钟，软件和模型下载另计。第 4 章本地路线共 75—115 分钟。如果选择线上路线，可以直接进入下一单元，再回到两条路线共用的调用程序。

先认识这三个角色

模型权重是需要加载的数据；Ollama 是负责加载并运行模型的服务；下一节的 Python 程序是向服务发送请求的客户端。装好 Ollama 不等于已经有模型，下载模型也不等于 Python 已经能连接服务。

课程以新准备的开发环境为起点，不使用任何预设的个人模型。M1 16 GB 的练习先从指定资料中使用的小模型 qwen2.5:3b 开始，限制为单次请求和短输出。它是起步候选，不是对速度或复杂任务效果的保证。

安装并启动 Ollama

在实际学习的 Mac 上安装 Ollama 的 macOS 应用，启动后新开一个终端。如果使用 Homebrew，可以选择下面的方式；不要重复安装多个版本：

# 通过已有的 Homebrew 安装本地模型服务应用；此步骤还不会下载模型权重。
brew install --cask ollama
# 启动本地模型服务；后续客户端才能向它发送请求。
open -a Ollama
# 确认 Ollama 命令可找到；预期显示版本，模型是否下载另用 list 检查。
ollama --version

没有 Homebrew 时，用 macOS 图形安装包完成安装即可；Homebrew 不作为课程的必学内容。Ollama 的软件入口收录在本节末的指定资料中。

检查服务：

# 向本地服务查询已下载模型；下载后应看到 qwen2.5:3b，空列表表示尚无模型。
ollama list

服务可用但列表为空时，只说明尚未下载模型。如果提示连接失败，先启动 Ollama 应用。也可在一个单独终端执行 ollama serve；该终端保持运行，其他操作用第二个终端。如果提示端口已占用，先检查应用是否已经启动，不要再启动第二个服务。

下载这次要用的模型

# 下载课程选用的模型权重；成功后才有条件加载它进行生成，下载等待另计。
ollama pull qwen2.5:3b
# 向本地服务查询已下载模型；下载后应看到 qwen2.5:3b，空列表表示尚无模型。
ollama list

下载结束后，预期列表包含 qwen2.5:3b。模型名中的标签要保留完整，不能把下载的 3b 随手改成另一个大小。模型下载量、运行内存和可用上下文不是同一个数；第一次只运行一个模型，观察系统内存，不同时启动其他重任务。

设置客户端要使用的地址

# 让共用程序选择本地连接检查；预期不要求线上账号密钥。
export LLM_MODE=local
# 指定本次请求的模型标识；应与 ollama list 中已下载的名称一致。
export LLM_MODEL=qwen2.5:3b
# 让主机上的客户端连接本机模型服务；预期请求发往 11434 端口的兼容接口。
export LLM_BASE_URL=http://127.0.0.1:11434/v1
# 清除当前终端遗留的线上密钥；本地练习由程序使用占位值。
unset LLM_API_KEY
# 清除其他实验留下的专用推理参数，减少当前模型因不支持该参数而报错的可能。
unset LLM_REASONING_EFFORT

这些变量只对当前终端及它启动的程序生效。重新打开终端时需要重新设置。127.0.0.1 表示运行客户端的这台机器，11434 是本章使用的模型服务端口，/v1 指向兼容接口前缀。

本章让客户端和模型在同一台电脑上，先不开放局域网访问。未来另一台电脑连接这台 M1 时，127.0.0.1 就不能继续指向服务器；那属于后面的部署与访问控制内容。

最后用一个只读请求查看接口能否连上：

# 只查询模型列表，最多等待 10 秒；预期返回 JSON，不生成回答或上传讲稿。
curl --fail --max-time 10 http://127.0.0.1:11434/v1/models

预期返回 JSON 模型列表。这里没有发送阅读问题，也没有读取讲稿。列表能返回，只证明服务入口可达；实际生成是否成功，要由共用调用单元继续验证。

**本单元完成条件：**模型已下载，接口可达，你能说清服务与 Python 客户端的区别。完成后跳过线上配置单元，进入“用同一个程序获得回答”。

本单元验收与参考答案

先完成上面的操作，再用自己的话回答。下面是核对思路和结果的参考，不要求背原句。

查看参考答案与通过标准

服务、模型、客户端各是什么？ 模型权重是运行推理所需的数据；Ollama 加载模型并提供服务；Python 客户端向服务发送问题、接收结果。安装客户端 SDK 不会自动安装模型。

怎样确认本节通过？ ollama list 中有完整的 qwen2.5:3b 标识；查询 /v1/models 成功返回 JSON。列表可达只证明接口连接成功，还没验证生成质量或知识库。

地址中的 127.0.0.1 指谁？ 指运行客户端的那个环境。本节客户端在主机上，因此指当前主机；以后放进容器，不能继续把它当宿主地址。
