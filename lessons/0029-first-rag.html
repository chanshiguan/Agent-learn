RAG 现在只多一条连接

顺序是：问题 → 当前作品可见片段 → 词面排序 → 上下文预算 → 模型解释 → 引用检查。生成模型没有被训练，知识库更新后换的是本次送入的证据。

现在动手写

先读每步的目的，再输入代码。代码块里的缩进属于程序；若同一处拆成多个连续块，写完这些块再检查。不要用课后完整参考文件覆盖自己的进度。

第 1 步：复用上一章的有据回答

检索只负责选材，生成函数负责解释。把两者连起来就是当前最小 RAG。

**写在哪里：**项目根目录下的 companion/query.py。 找到下面这段原文，把它完整替换成新内容。上下文行也包含在替换范围内，不要重复留下。

定位：本步骤要替换的原文 
from .rag import retrieve

先理解：from ... import ... 只引入本步骤要用的名字。以点开头的路径指向 companion 包里的文件；先确认那个文件已在前面的步骤创建。

from .rag import retrieve, answer

**写完后应当怎样：**请求中的资料由检索自动提供。

第 2 步：增加问答分支，保留检索观察入口

排错时仍可单独 search；不要把所有失败都藏在 ask 的最终答案后面。

**写在哪里：**项目根目录下的 companion/query.py。 找到下面这段原文，把它完整替换成新内容。上下文行也包含在替换范围内，不要重复留下。

定位：本步骤要替换的原文 
    result = {"question":args.question,"hits":hits}

**先理解：**对照旧段和新段，看本次增加了哪个条件或配置值。它应当只改变上面说明的行为；其余输入与输出继续沿用。

    result = answer(args.question,hits) if kind == "ask" else {"question":args.question,"hits":hits}

**写完后应当怎样：**ask 返回引用与解释，search 保持原样。

第 3 步：给命令入口增加 ask

这里只增加一个分支，并在选中时导入对应模块；前期命令不会提前加载后期功能。

**写在哪里：**项目根目录下的 companion/__main__.py。 找到下面这段原文，把它完整替换成新内容。上下文行也包含在替换范围内，不要重复留下。

定位：本步骤要替换的原文 
        main('search')

先理解：from ... import ... 只引入本步骤要用的名字。以点开头的路径指向 companion 包里的文件；先确认那个文件已在前面的步骤创建。

        main('search')
    elif command == "ask":
        from .query import main
        main('ask')

**写完后应当怎样：**旧命令仍可运行，新命令调用你刚完成的函数。

运行并观察

# 使用刚才的词面检索，再把候选证据交给真实模型；预期回答含可回查的引用。
python -m companion ask "讲稿怎样解释文言文序言与白话日记的关系？"
# 第一份回答保留作对照；下一条 ask 会覆盖工作文件 ask.json。
cp data/live/ask.json data/live/ask-supported.json
# 提问资料未提供的精确信息；预期明确不足，不借常识编造版本页码。
python -m companion ask "这五讲采用哪家出版社哪一版原著？请给出每讲的准确页码。"
# 单独留下不足回答，下一章建立评分规则时回看这两个案例。
cp data/live/ask.json data/live/ask-insufficient.json

打开 data/live/ask-supported.json 和 data/live/ask-insufficient.json，逐条核对 citations 和 sources：合法编号只是起点，还要检查对应片段是否真的支持回答。允许文学解读有差异，但不允许凭空添加证据。

亲手拆开一条回答

用不同颜色标出：直接复述讲稿的句子、模型组织的解释、超出资料的内容。若一句话声称“鲁迅原文说”，回查它是否真的出现在已提供资料里；讲稿讲述者的说法不能自动升级为原著引文。

下一次把同一个问题用 --book "三国演义" 运行。没有可见证据时，程序直接返回不足，不调用生成模型。这比“让模型随便答，再提醒可能不准”更容易验证。

结果不稳定时

格式错误要留下失败记录，不能用手工改 JSON 冒充模型成功。证据有、答案偏，排查 Prompt 和模型；证据没有，排查检索。第 8 章把今天这套人工检查做成固定题集，之后每次优化都沿用。

本章的 RAG 比第 5 章多了什么？

自动检索替代了手工选材，其余仍是把资料与问题交给模型并核对引用。

没有证据时，为什么不请模型发挥？

本产品这一模式承诺按知识库回答。调用模型自由发挥会破坏这一边界；可以明确提示补充资料或调整问题。

**通过证据：**保留一个有依据回答、一个不足回答、一个错误作品结果，并逐句核对至少一条文学解释。

from companion.rag import answer,retrieve
