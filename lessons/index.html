Prompt Engineering
中文完整课程

这套课程用中文重新组织 Anthropic 交互式教程、OpenAI Prompt Engineering 指南和 Google Prompt Design Strategies 的全部核心内容。你可以只学这套课，不需要在三份英文资料之间来回跳转。

目标：从“会问模型”进阶到“会设计、测试和维护 Prompt 系统”

内容边界：课程完整覆盖三份资料的知识点，但不是原文翻译或逐字复制。所有讲解、比喻、案例和练习均为中文重写，并对旧版、供应商特定或已不适用的内容做了标注。
学习方式：请直接按下方第 1–7 课学习。你不需要访问 Anthropic、OpenAI 或 Google 的原始网页；课程中出现三家公司名称，只是在说明某个知识点的来源。

学习路线

  1. 三份资料的总地图
    先看清 Anthropic、OpenAI、Google 各自在解决什么问题。
  2. 基础结构、角色、输入与边界
    学会组织消息，选模型，区分指令和资料。
  3. 输出控制、预填充与 Few-Shot
    让格式可解析，让范例真正展示边界。
  4. 推理、幻觉、上下文与 Grounding
    判断何时补理由、何时补资料、何时应该调工具。
  5. 复杂 Prompt、链式流程、工具与 Agent
    从单次问答走到计划、执行、验证和恢复。
  6. 参数、迭代、Eval 与生产维护
    把 Prompt 从“感觉不错”变成可测试、可回归的工程资产。
  7. 现代模型、长上下文与厂商差异
    理解 GPT、推理模型、Gemini 3 和旧版 Claude 建议为何不能混用。

怎样才算学会

  • 能从失败现象判断该改 Prompt、上下文、参数、模型还是工具。
  • 能用一套稳定结构写出目标、输入、约束、范例和输出格式。
  • 能用固定 Eval 比较两个 Prompt，而不是只说“新版感觉更好”。
  • 能设计一个需要查资料、调工具、校验结果的小型 Agent 流程。
建议节奏：每次只学一课，完成页底检索题后再继续。“看完”不等于“会用”，主动回忆和动手修改 Prompt 才会建立长期记忆。
