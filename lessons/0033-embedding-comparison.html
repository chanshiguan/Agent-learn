相同资料、相同问题，才值得比较

这一轮固定为 80/16 的资料快照。不要拿 600 字的关键词结果和 80 字的向量结果直接下结论，那同时改变了两个变量。

运行并观察

# 在相同小块上重跑词面基线；先保存输出，再做向量对照。
python -m companion search "徐锡麟"
# 保留当前80/16快照下的词面结果，不能拿旧600字块的结果代替。
cp data/live/search.json data/live/keyword-name-small.json
# 编码同一个问题；观察精确人名是否仍然容易找到，不预设向量一定更好。
python -m companion direct-vector "徐锡麟"
# 留下精确人名的向量结果，下一次向量查询会覆盖工作文件。
cp data/live/direct-vector.json data/live/vector-name-small.json
# 再运行上一章记录的同义问法，检验它是否真的改善。
python -m companion direct-vector "开头古雅的文字和后面的记录有什么关系"
# 记录同义问法的向量结果，后续混合检索继续比较这个问题。
cp data/live/direct-vector.json data/live/vector-paraphrase-small.json
# 也在当前小块上查询同义问法，补齐同一问题、同一资料下的词面对照。
python -m companion search "开头古雅的文字和后面的记录有什么关系"
# 单独保存这份小块词面结果，与刚才的向量结果逐条比较。
cp data/live/search.json data/live/keyword-paraphrase-small.json

建一张四列表：问题、词面命中关键句、向量命中关键句、理由。至少放精确人名、同义问法和无答案三题。最后一题即使得到很高相似度，也不表示资料能回答出版社页码。

做一次手工核查

从前五条里找出排名最高却不相关的一条，看看是不是主题接近、关系却不同。中文否定、人物混淆、短片段脱离语境，都可能造成这种结果。保留它，第 12 章用来评估混合检索或重排。

本次公开样本实测中，“开头古雅的文字和后面的记录有什么关系”的向量检索前五条没有命中第一讲，反而多来自第三讲。这是一个真实的未改善例子，见验证记录。你的模型和资料若得到不同结果，就记录自己的结果，不需要复现老师的排名。

当前 direct-vector 每次重算所有片段，便于看清流程，但越来越慢。第 10 章会保存向量；它解决重复计算和检索存储问题，不自动提高语义质量。

向量分数高但资料没有页码，能否回答？

不能。相似只说明表示接近，资料缺少的事实仍然缺少。

比较时为什么固定切块？

否则无法区分改善来自编码器还是块大小。先只改变检索方法。

**通过证据：**三类问题的逐题对照表，至少保留一个未改善或仍有风险的例子。
