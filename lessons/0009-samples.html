先用一套人人都能取得的小样本

公开课程附带五份新编《狂人日记》讲解稿，位于练习目录的 data/input/。可编辑的 Markdown 正文在 公开样本目录，不是私人授课资料，也不是原著全文。课程中的问题保持不变，参考证据来自这套新稿。

文件 主要内容
06 《狂人日记》第一讲两种叙述声音.docx 文言序言、白话日记及叙述者
07 《狂人日记》第二讲月光与平等.docx 象征解读的依据和边界
08 《狂人日记》第三讲吃人的历史联想.docx 文学列举与历史证据的区别
09 《狂人日记》第四讲不可靠叙述.docx 人物感受、推断与社会批判
10 《狂人日记》第五讲传统与未来.docx 为传统提供理由，理解结尾的呼吁

打开第一讲，记一处讲解者的解释；再打开第五讲，找一处标明出处的短引句。现在不用抄长段，只记文件名、定位词和内容类别。看到第三讲的“徐锡麟／徐锡林”说明时，留意题目写法与核对文本的差别，不要在导入时悄悄统一。

为什么读出一段仍可能正确

Word 的屏幕行数、手动换行和段落数量不是一回事。这批公开样本特意用一个正文段落保存每讲内容，在段内保留换行；因此程序读出 1 是预期现象。这个设计用于后面的切块实验，不表示一讲在文学上只有一个意思。

第一章先按文件结构读取，第 11 章再比较不同切法。标题文字写在正文里，也不代表 Word 已使用标题样式；这正是“按标题切分”可能没有效果的原因。

在实际学习电脑上准备

解压课程包，或下载公开仓库后，进入 courses/00-classics-reading-foundations/examples/。先检查 data/input/ 是否已有五份 DOCX；附带的文件可以直接使用。还没有配置 Python 时，先用 Markdown 阅读，不必在此提前安装所有工具。

第 1 章完成虚拟环境和 requirements.txt 安装后，可以在练习目录运行：

# 从课程附带的公开 Markdown 生成五份 Word 样本及来源指纹；不需要私人 ZIP 或网络。
# 如果已有相同文件，保留它们；遇到不同内容则停止，避免覆盖你的修改。
python prepare_samples.py

预期显示“已准备 5 份课程自编讲解稿”。完整源码在代码索引中；此时知道它从哪里读、往哪里写即可，不要求提前掌握 DOCX 的生成过程。data/sample-manifest.json 记录公开源文件、SHA-256 和字符数，不写课程编写者的电脑路径。

Git 版本只跟踪这五份明确列出的公开样本和清单；其他业务数据仍忽略。Docker 构建继续排除整个 data/，后面的练习通过挂载传入输入，避免把运行资料固化进镜像。

本单元验收与参考答案

查看参考答案与通过标准

这五份是什么？ 课程新编的《狂人日记》讲解稿，文件序号为 06—10；它们既不是私人原讲稿，也不是原著全文。讲解中的观点与标明出处的原著引句要分开。

为什么各读出一段也可能正确？ 本批 DOCX 用一个段落保存正文，段内换行不会增加段落数。程序按文档结构计数，不按屏幕行数计数。

**通过证据：**五份样本可定位，第一讲可打开，来源清单有对应指纹。项目卡记录一处讲解和一处需回查的引句或转述，位置可自行选择。
