现在动手写

先读每步的目的，再输入代码。代码块里的缩进属于程序；若同一处拆成多个连续块，写完这些块再检查。不要用课后完整参考文件覆盖自己的进度。

第 1 步：先只确认文件与段落数

读取库替我们解析 Word 内部结构。此时只验证有没有读到正确文档，还不进行任何模型调用。

**写在哪里：**项目根目录下的 peek_docx.py。 先在编辑器新建文件；父目录没有时先建目录。不要把代码正文当成终端命令执行。

**先理解：**Path 表示文件位置；Document 负责解析；len 统计正文段落对象。

# 目的：读取库替我们解析 Word 内部结构。此时只验证有没有读到正确文档，还不进行任何模型调用。
# 预期：运行 python peek_docx.py，公开第一讲应显示 1 个正文段落。
from pathlib import Path
from docx import Document

# 固定第一份输入，先确认程序和人打开的是同一份讲稿。
source = Path("data/input/06 《狂人日记》第一讲两种叙述声音.docx")
document = Document(source)
print("文件：", source.name)
print("正文段落数量：", len(document.paragraphs))

**写完后应当怎样：**运行 python peek_docx.py，公开第一讲应显示 1 个正文段落。

第 2 步：加上可回查的文字预览

段落数量对，并不代表选对了文件。打印少量原文，让你能在讲稿页面中逐字核对。

**写在哪里：**项目根目录下的 peek_docx.py。 在文件末尾另起一行，接着写下面这一段；已有内容保留。

**先理解：**循环内缩进四个空格；[:80] 仅限制这次显示。

# 目的：段落数量对，并不代表选对了文件。打印少量原文，让你能在讲稿页面中逐字核对。
# 预期：再次运行会多显示位置 1 和开头 80 字；原文件没有改变。
# 保留原位置并限制预览长度，既能回查，也不会把全文刷满终端。
for position, paragraph in enumerate(document.paragraphs, start=1):
    print("段落位置：", position)
    print("开头文字：", paragraph.text[:80])

**写完后应当怎样：**再次运行会多显示位置 1 和开头 80 字；原文件没有改变。

运行并观察

# 运行你刚写的预览程序；本课程第一、第二讲都应显示 1 个正文段落。
python peek_docx.py

对于本课程选中的第一讲，预期正文段落数量为 1。先核对打印的文件名和开头文字，确认它们与刚打开的第一讲一致。显示 80 个字符只限制终端预览，没有截短 document 中的内容。

看到一整页文字却只读出一段，不一定是程序漏读。Word 的屏幕行数、段内换行和真正的段落是三回事：这五份公开样本把每讲正文放在一个段落里，内部仍有换行，所以 document.paragraphs 只有一个元素。这里数的是文件结构，不是句子、屏幕行或文学上的一个意思。下一节保存全文后，还会从开头、中间和结尾核对，不能只凭数字 1 就宣布读取正确。

把语法和这次任务对上

写法 在这里有什么用
Path(...) 表示文件位置，后面可以取文件名或检查文件是否存在
Document(source) 让读取库解析 Word 文件，不把 DOCX 当普通文本硬读
document.paragraphs 得到正文段落列表；不会自动包含页眉、脚注和所有表格文字
enumerate(..., start=1) 同时取到位置和段落，方便人从第一段开始核对
paragraph.text 取出当前段落里的文字
[:80] 只拿开头一小段来观察

Python 用缩进表示哪些语句属于循环。这里两条循环内的 print 都缩进四个空格。代码如果报 IndentationError，先检查缩进，别先改文件路径。

为什么不能直接使用 open(...).read() 读 DOCX

DOCX 内部包含结构化的文档部件，并不是按 UTF-8 保存的一整篇纯文本。这里借助读取库取正文段落。你只需要知道这层区别，不必在第一章自己解析 Word 的内部格式。

查看参考答案与通过标准

第一讲和第二讲各有几段？ 本课程附带版本各有 1 个正文段落。需要同时在 Word 中核对预览文字，不能仅凭这个数字判断文件选对了。

80 改成 120 会改变原文吗？ 不会。paragraph.text[:120] 只截取打印时的预览；源 DOCX 和已读入的完整段落不变。

把文件名写错后先检查什么？ 工作目录、真实文件名与引号。能导入读取库却找不到文件时，重装库不能修正路径。

**通过证据：**保留两讲的运行输出，能在源文件中找到打印的开头文字；改错文件名会失败，改回后恢复。
