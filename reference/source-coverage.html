课程的修正规则

  1. 保留可迁移的原理，不把某一家 API 的字段当成永恒标准。
  2. 旧教程与新文档冲突时，讲清历史用途，并采用当前更安全的实践。
  3. 参数、模型名称、产品状态和库推荐都标为易变信息，需要按当前版本复核。
  4. 所有技巧最后都回到 Eval：在你的真实任务上稳定有效，才算有效。
