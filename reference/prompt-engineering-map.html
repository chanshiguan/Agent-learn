失败诊断顺序

1. 输出被截断？→ 2. 任务说清了？→ 3. 资料够用？→ 4. 边界范例够用？→ 5. 模型有能力？→ 6. 工具或代码正确？

什么时候用哪个技巧

现象先尝试不要立即做
答非所问清晰化目标与输入无限增加形容词
格式不稳定明确格式 + Few-Shot相信“返回 JSON”就足够
事实不准补可信上下文只改语气
边界分类错补一个边界范例一次加十几个范例
答案是空的检查 finish_reason 和 token 上限认定是 Prompt 错了
修改后“感觉更好”用同一组 Eval 重跑换题再比较

一次可信的 Prompt 实验

  1. 固定模型、参数、测试题和评分规则。
  2. 记录原版分数和具体错例。
  3. 只修改 Prompt 的一个部分。
  4. 重跑同一组题，对比总分和错误类型。
  5. 没有证据时，结论写“还不确定”。
